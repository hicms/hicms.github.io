Install in Chrome

  1. Download the ZIP.

    Get the Chrome package from the latest GitHub release and extract it.

  2. Load the extension.

    Open chrome://extensions, enable Developer mode, and choose Load unpacked. Select the extracted folder.

  3. Open AskTab.

    Sign in and choose an available model.

Chrome Web Store listing is not yet available.
